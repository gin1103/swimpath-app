# SwimPath

A self-guided swim training PWA with skill-tree progression, session tracking, and a bilingual 中文/English UI — covering freestyle, breaststroke, backstroke, butterfly, and a full Total Immersion route.

## Project layout

- `app/` — the SwimPath application source (React + TypeScript + Vite + Dexie/IndexedDB PWA)
- `PRD.md` — product requirements document
- `CLAUDE.md` — development workflow notes
- `swimming coach.md` — teaching content knowledge base (technique points, drills, pass criteria per skill)
- `skill-teaching-module-mapping.md` — mapping between skills and teaching modules

## Getting started

```bash
cd app
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
